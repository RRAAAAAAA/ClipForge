# ClipForge MVP
Needs: Node 20+, ffmpeg, yt-dlp (pip install -U yt-dlp).
Run: `npm install && ANTHROPIC_API_KEY=sk-ant-... npm start` then open http://localhost:3000
Deploy on Railway: push this folder, it builds from the Dockerfile; set ANTHROPIC_API_KEY.
Only works on videos with English captions. Use content you have permission to clip.
